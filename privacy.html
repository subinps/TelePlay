Privacy Policy

Last updated: February 14, 2024

1. Introduction

TelePlay ("we", "our", or "us") is an open-source self-hosted media server application. This Privacy Policy explains how TelePlay handles your data.

2. Data Collection and Usage

TelePlay is self-hosted software. This means:

  • We (the developers) do not host, store, or have access to any of your files, messages, or personal data.
  • Your data resides strictly between Telegram's servers and your own self-hosted server (VPS, local machine, etc.).
  • All authentication and file retrieval is done directly via the Telegram API using credentials you provide.

3. Telegram Data

TelePlay acts as a client for the Telegram API. It accesses:

  • Files you upload to the bot.
  • Messages in the configured storage channel.
  • Basic profile information (User ID, First Name) for authentication.

This data interacts only with Telegram's servers and your TelePlay instance.

4. Third-Party Services

  • Telegram: The app relies on Telegram's API. Please refer to Telegram's Privacy Policy.
  • TMDB (Optional): If enabled, the app may fetch metadata (posters, descriptions) from The Movie Database (TMDB). Please refer to TMDB's Privacy Policy.

5. Analytics

The core TelePlay application does not contain any tracking or analytics code. It does not send crash reports or usage statistics to the developers.

6. Contact Us

If you have questions about this Privacy Policy, please open an issue on our GitHub repository.
